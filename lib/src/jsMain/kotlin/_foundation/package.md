# Package com.github.jangalinski.kobweb.tabler._foundation

Shared, non-widget infrastructure for the library. This package defines cross-concept semantic contracts such as `Component`, `Style`, `Behavior`, and `Size`, plus narrowly scoped shared value types.

Component APIs should use their owning concept package rather than expose `_foundation` implementation details.

See [Tabler base documentation](https://docs.tabler.io/ui/base).
