# Package com.github.jangalinski.tabweb.avatar

Tabler avatar renderers and their structured data models, including avatar content, size, shape, color, status, and avatar lists.

See [Tabler Avatar](https://docs.tabler.io/ui/components/avatar).


## Class reference

Every class this component ships, grouped by what it changes. A name in braces stands for a family — {color} is any base color, {breakpoint} any responsive step.

* COMPONENT avatar		Container element
* PART avatar-brand		Small brand mark in the bottom corner
* PART avatar-cover		Pulls the avatar over the element above it, with a ring
* PART avatar-upload-text		Label inside an empty upload slot
* PART avatar-list		Wrapper that spaces several avatars in a row
* STYLE avatar-square		Rounded corners instead of a circle
* STYLE avatar-rounded		Fully round, the default shape
* STYLE avatar-upload		Dashed empty slot for a picture that is not set yet
* MODIFIER avatar-list-stacked		Overlaps the avatars in the list
* COLOR bg-{color}		Any base color for an avatar with initials, for example bg-azure-lt
* SIZE avatar-{size}		From avatar-xxs to avatar-2xl; avatar-list-{size} sizes a whole list
