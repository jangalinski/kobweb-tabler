# Button

https://docs.tabler.io/ui/components/button

## Summary

Buttons in every color, size and shape, with icons, loading states, social styles and button groups.

## Class reference

Every class this component ships, grouped by what it changes. A name in braces stands for a family — `{color}` is any base color, `{breakpoint}` any responsive step.

| Name | Type | Description |
| --- | --- | --- |
| `btn` | component | Container element, on a button or a link |
| `btn-action` | part | Quiet icon button for a card or a table row |
| `btn-actions` | part | Wrapper that groups action buttons |
| `btn-list` | part | Spaces several buttons in a row; add btn-list-center to center them |
| `btn-group` | part | Joins buttons into one control; btn-group-vertical stacks them |
| `btn-toolbar` | part | Groups several button groups |
| `btn-check` | part | Hidden input that turns a label into a toggle button |
| `btn-outline` | style | Transparent fill with a colored border |
| `btn-ghost` | style | No fill and no border until hovered |
| `btn-link` | style | Renders as a plain link |
| `btn-pill` | modifier | Fully rounded ends |
| `btn-square` | modifier | Sharp corners |
| `btn-icon` | modifier | Square button holding only an icon; it still needs an aria-label |
| `btn-floating` | modifier | Pins the button to the bottom corner of the viewport |
| `btn-loading` | behavior | Hides the label and draws a spinner; pair it with disabled and aria-busy |
| `btn-animate-icon` | behavior | Animates the icon on hover, with -pulse, -rotate, -shake, -tada or -move-start |
| `btn-{color}` | color | Any base or social color, for example btn-primary or btn-facebook |
| `btn-sm` | size | Small size |
| `btn-lg` | size | Large size |
| `btn-xl` | size | Extra large size |
