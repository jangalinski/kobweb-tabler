# Icon

https://docs.tabler.io/ui/components/icon

## Summary

Tabler Icons are over 5,000 MIT-licensed SVG icons drawn for Tabler. This page shows how to embed, size, color and animate them.

## Class reference

Every class this component ships, grouped by what it changes. A name in braces stands for a family — `{color}` is any base color, `{breakpoint}` any responsive step.

| Name | Type | Description |
| --- | --- | --- |
| `icon` | component | Applied to the svg element |
| `icon-filled` | style | Fills the shape with the current text color |
| `icon-inline` | style | Aligns the icon with the surrounding line of text |
| `icon-pulse` | behavior | Pulsing animation |
| `icon-tada` | behavior | Shake animation |
| `icon-rotate` | behavior | Continuous rotation |
| `icon-sm` | size | 1rem |
| `icon-md` | size | 1.5rem, with a thinner stroke |
| `icon-lg` | size | 2.5rem |
