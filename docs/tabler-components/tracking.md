# Tracking

https://docs.tabler.io/ui/components/tracking

## Summary

A row of colored blocks that shows one status per time period, for uptime and activity logs.

## Class reference

Every class this component ships, grouped by what it changes. A name in braces stands for a family — `{color}` is any base color, `{breakpoint}` any responsive step.

| Name | Type | Description |
| --- | --- | --- |
| `tracking` | component | Container element |
| `tracking-block` | part | One block in the strip, colored with a bg-{color} utility |
| `tracking-squares` | modifier | Draws the blocks as equal squares instead of tall bars |
