# Data grid

https://docs.tabler.io/ui/components/datagrid

## Summary

Use the data grid component to display detailed information about your product. The data is displayed as a column of items consisting of a title and content.

## Class reference

Every class this component ships, grouped by what it changes. A name in braces stands for a family — `{color}` is any base color, `{breakpoint}` any responsive step.

| Name | Type | Description |
| --- | --- | --- |
| `datagrid` | component | Container element, a responsive grid of label and value pairs |
| `datagrid-title` | part | Label above a value |
