# Timeline

https://docs.tabler.io/ui/components/timeline

## Summary

A timeline is a list of events in order, with an icon or an avatar per event and a card for its content, for activity feeds and histories.

## Class reference

Every class this component ships, grouped by what it changes. A name in braces stands for a family — `{color}` is any base color, `{breakpoint}` any responsive step.

| Name | Type | Description |
| --- | --- | --- |
| `timeline` | component | Container element |
| `timeline-event` | part | One entry on the timeline |
| `timeline-event-icon` | part | Marker on the line, next to the entry |
| `timeline-event-card` | part | Card holding the content of the entry |
| `timeline-simple` | style | Drops the cards and the connecting line for a plain list |
