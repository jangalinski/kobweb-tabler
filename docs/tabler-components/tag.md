# Tag

https://docs.tabler.io/ui/components/tag

## Summary

Use tags to show compact metadata values with optional media, badges, and remove actions.

## Class reference

Every class this component ships, grouped by what it changes. A name in braces stands for a family — `{color}` is any base color, `{breakpoint}` any responsive step.

| Name | Type | Description |
| --- | --- | --- |
| `tag` | component | Container element |
| `tag-avatar` | part | Avatar at the start of the tag |
| `tag-flag` | part | Country flag at the start of the tag |
| `tag-payment` | part | Payment provider logo at the start of the tag |
| `tag-icon` | part | Icon slot inside the tag |
| `tag-check` | part | Checkbox inside the tag, for a removable filter |
| `tag-badge` | part | Badge appended to the tag |
| `tag-list` | part | Wrapper that spaces several tags in a row |
