# Pagination

https://docs.tabler.io/ui/components/pagination

## Summary

Pagination splits a long list or table into pages and lets the user move between them, with sizes, icons and disabled states.

## Class reference

Every class this component ships, grouped by what it changes. A name in braces stands for a family — `{color}` is any base color, `{breakpoint}` any responsive step.

| Name | Type | Description |
| --- | --- | --- |
| `pagination` | component | Container element, an unordered list |
| `page-item` | part | One entry in the pager |
| `page-link` | part | The clickable element inside an entry |
| `page-item-title` | part | Page name, for a pager that names pages instead of numbering them |
| `page-item-subtitle` | part | Small uppercase label above the title |
| `pagination-outline` | style | Outlined entries instead of filled ones |
| `pagination-circle` | style | Round entries |
| `pagination-sm` | size | Small size |
| `pagination-lg` | size | Large size |
