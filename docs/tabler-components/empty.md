# Empty state

https://docs.tabler.io/ui/components/empty

## Summary

An empty state is the placeholder shown when there is no content yet, on first use, after a search with no results or on an error screen.

## Class reference

Every class this component ships, grouped by what it changes. A name in braces stands for a family — `{color}` is any base color, `{breakpoint}` any responsive step.

| Name | Type | Description |
| --- | --- | --- |
| `empty` | component | Container element |
| `empty-header` | part | Large muted text above the title, usually an error code |
| `empty-img` | part | Illustration slot |
| `empty-icon` | part | Icon slot, an alternative to the illustration |
| `empty-title` | part | Heading that says what is missing |
| `empty-subtitle` | part | Explanation under the title |
| `empty-action` | part | Row holding the call to action |
| `empty-bordered` | style | Adds a dashed border around the whole block |
