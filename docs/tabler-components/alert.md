# Alert

https://docs.tabler.io/ui/components/alert

## Summary

Alerts report the result of an action or a problem to fix, in success, info, warning and danger variants, with icons, links and a dismiss button.

## Class reference

Every class this component ships, grouped by what it changes. A name in braces stands for a family — `{color}` is any base color, `{breakpoint}` any responsive step.

| Name | Type | Description |
| --- | --- | --- |
| `alert` | component | Container element |
| `alert-heading` | part | Title line above the message |
| `alert-description` | part | Secondary text under the title |
| `alert-icon` | part | Icon slot, sized and colored with the alert |
| `alert-link` | part | Link inside the message, matched to the alert color |
| `alert-action` | part | Underlined link on its own line, for the next step |
| `alert-list` | part | List inside the alert, with the default list margin removed |
| `alert-important` | style | Solid fill in the alert color, with white text |
| `alert-minor` | style | Drops the tinted background, keeps a plain border |
| `alert-dismissible` | style | Reserves room on the trailing edge for the close button |
| `alert-{color}` | color | Any base color, for example alert-success, alert-blue or alert-muted |
